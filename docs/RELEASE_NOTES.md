# 0.1.0-beta.1

First public beta for Minecraft Java 1.21.1 / NeoForge, targeting Create 6.0.10.

- Four hammer tiers: Stone, Iron, Diamond and Pneumatic.
- In-world sheet crafting using an offhand input and raised work surface.
- Material progression, compatible pressing recipe support and a shared strike cooldown.
- Two-strike Sturdy Sheet crafting with Pneumatic on raised magma.
- Create wrench integration and backtank-powered ordinary strikes/combat.
- Approved weathered 3D models, coarser wooden handles, dedicated wedge textures and corrected copper/brass joins.
- Supplied icon embedded; matching workshop banner and player guide included.

Gameplay code, hammer models, textures, recipes and item IDs are unchanged from the approved alpha.11 baseline. This beta step updates version metadata, branding, documentation and release packaging.

The owner confirmed swings, left-handed holding, inventory display, sheet crafting, textures and the Z-fighting fix. Screenshots are complete. A real two-player session is deferred at the owner's request. See `RELEASE_AUDIT.md` for the final build and package verification record.
